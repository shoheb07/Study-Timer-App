# Study-Timer-App
The Study Timer App is a productivity-focused web application developed using HTML, CSS, and JavaScript. The application helps users manage study sessions using a countdown timer based on the Pomodoro technique.

# Study Timer App

## Project Overview

The Study Timer App is a Pomodoro-style productivity application that helps users manage focused study sessions using a countdown timer.

The project is developed using HTML, CSS, and JavaScript.


# Features

- Countdown timer
- Start, pause, reset controls
- Study session alerts
- Responsive UI


# Technologies Used

- HTML5
- CSS3
- JavaScript

# Run Project

Open index.html in browser.
